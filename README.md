# SENDERGTRSD — Premium Technology Website

Modern, responsive, English-language technology concept website.

## Run locally

Open `index.html` in a browser or run `python -m http.server 8000`.

## Deploy to GitHub Pages

Upload the **contents** of this folder (including `index.html` and `assets/`) to the root of `sendergtrsd/sendergtrsd-website`, then configure Settings → Pages → Deploy from branch → main / (root).

## Important

All products and prices are illustrative. No orders, payments, or contact messages are processed. Google Fonts require internet connectivity.
